# Flix Seats

[Live app](https://flix.ariobarin.com) for finding FlixBus trips and viewing current seat availability. It is read-only and does not select seats or create bookings.

## Develop

Requires Node.js 24 and the Vercel CLI. Run `vercel link` once, then `vercel dev`.

GitHub Actions checks every push to `main` and each pull request. Vercel deploys `main` automatically and creates branch previews.
